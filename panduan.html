📖 Panduan Hafiza Bakery

Website ini menampilkan menu kue yang disimpan di Google Sheets. Pengunjung bisa melihat menu, menambah ke keranjang, dan memesan via WhatsApp.

Untuk Pengunjung

🎂 Lihat & Pesan Kue

Pilih kue di menu, klik tombol + untuk masukkan ke keranjang. Setelah selesai, buka keranjang lalu klik Pesan via WhatsApp. Pesanan akan terbuka di WhatsApp dengan format otomatis.

🔍 Cari Kue

Gunakan kotak pencarian di header untuk mencari nama atau deskripsi kue.

Fitur Database

  • Menu Kue — daftar kue yang status-nya Active tampil di website.
  • Admin Panel — kelola menu (tambah, edit, hapus) tanpa membuka Google Sheets.
  • Keamanan — password & ID spreadsheet disimpan di Script Properties (tidak ada di kode frontend).

Untuk Admin

🔐 Masuk Panel Admin

Klik tombol 🔐 Admin di header → masukkan password Bismillaah.

📋 Kelola Menu (CRUD)

  • Lihat semua kue (termasuk Hidden)
  • Edit nama, harga, foto, deskripsi, status
  • Hapus kue
  • Tambah kue baru lewat tab ➕

Status Active = tampil di website. Status Hidden = disembunyikan.

Setup Teknis

  1. Buat Google Spreadsheet dengan sheet Cakes.
  2. Paste Code.gs ke Apps Script.
  3. Set Script Properties: SPREADSHEET_ID dan ADMIN_PASSWORD = Bismillaah.
  4. Deploy sebagai Web App (Anyone) → copy URL /exec.
  5. Paste URL ke script.js → const API_URL.
  6. Jalankan seedInitialData() sekali untuk isi data awal.
  7. Upload frontend ke GitHub Pages.
